## 개념
    병합 정렬 + 삽입 정렬을 섞은 하이브리드 정렬

    * 정의: 이미 부분적으로 정렬된 구간(run)을 찾아 병합하는 정렬
    * 실제 데이터는 완전 랜덤이 아닌 경우가 많음
    * 부분 정렬 상태를 활용하면 더 빠르게 정렬 가능
    * 자바 Array.sort(Object[]), 파이썬 sorted()의 기본 정렬
    * 핵심 특징
        * 안정 정렬
        * 최악 O(n log n)
        * 실전 성능 매우 우수

## 복잡도
* 최선 시간 복잡도: O(n)
* 평균 시간 복잡도: O(n log n)
* 최악 시간 복잡도: O(n log n)
* 공간 복잡도: O(n)

## 동작 원리
1. 최소 길이 설정(32~64)
2. 작은 구간은 삽입 정렬
3. Run들을 스택에 쌓음
4. 병합 규칙에 따라 merge 수행
