## 연역: 펼 연(演)과 풀어낼 역(繹)

보편적인 원리나 대전제에서 구체적인 사실이나 결론을 끌어내어 펼치는 논리적 추론 방식

큰 전제 -> 작은 전제 -> 결론

```
모은 인간은 죽는다.
소크라테스는 인간이다.
따라서 소크라테스는 죽는다.
```
이 방식은 전제가 참이면 결론도 반드시 참이 된다.




연역이 일반적인 사실로부터 구체적인 결론을 도출한다는 말은 보통 맞지만 실제로는 부정확하다.<br>
연역의 본질은 '일반 -> 특수'가 아니라 '전제가 참이면 결론이 반드시 참이되는 추론 구조'이다.

```
전제1. 만약 비가 오면 길이 젖는다.
전제2. 지금 비가 온다
결론 길이 젖는다.
```
위의 예시는 일반적인 사실이라는 표현이 애매하다. 단순히 조건문 논리 구조이다.

* 어떤 상황에서는 길이 안 젖을 수도 있다.
* 지붕이 덮여있어도 길이 안 젖는다.
* 길이 방수 처리되어 있을 수 있다.

형식적으로는 연역적 논증이다. 다만 전제가 항상 참일 수 없다.

연역에는 타당성(논리 구조가 맞는지)과 건전성(전제도 실제로 참인가)을 구분해야 한다.

"어떤 상황에선 안 젖을 수도 있다"는 지적은 논증의 **'타당성(Validity)'** 과 **'건전성(Soundness)'** 의 차이를 잘 보여준다.

구조가 완벽해도 전제(비가 오면 무조건 젖는다)가 현실에서 거짓일 수 있다면, 그 논증은 타당하지만 건전하지는 않은 것이 된다.

따라서 연역은 전제가 참일 때 결론이 반드시 참이 되도록 구성된 논리적 추론이다.


### Modus Ponens: 긍정하는 방식 또는 확정하는 방식이라는 뜻이며 기본적인 연역 규칙이다.

```
1. P이면 Q다.
2. P다.
3. Q다.
```
전제가 참이면 결론이 반드시 참이되는 구조이다.
이 구조는 프로그래밍의 조건문에서도 사용한다.

```java
if(P){
    Q;
}
```

### Modus Tollens: 부정하는 방식이라는 뜻이며 조건문의 결과를 부정해서 원인을 부정하는 추론 방식이다.
```
1. P라면 Q이다.
2. Q가 아니다.
3. 따라서 P도 아니다.
```
이 역시 전제가 참이면 결론이 반드시 참이 되는 연역이다.

```java
if (!Q) {
   // 그러면 P가 아니다
}
```

| 구분 | 구조 | 의미 |
| - | - | -|
| Modus Ponens | P → Q / P / ∴ Q  | 원인을 긍정하면 결과도 긍정|
| Modus Tollens | P → Q / ¬Q / ∴ ¬P  | 결과를 부정하면 원인도 부정|


## 귀납: 돌아갈 귀(歸)'와 '거두어들일 납(納)
개별적이고 특수한 사실이나 사례를 거두어들여 일반적인 원리나 보편적 법칙으로 돌아가게 하는 추론 방식

사례1, 사례2, 사례3 -> 일반화

```
백조 A는 흰색이다.
백조 B도 흰색이다.
내가 본 백조는 모두 흰색이다.
따라서 모든 백조는 흰색일 것이다.
```
나중에 검은 백조가 발견될 수도 있다. 그래서 귀납은 확률적 추론이고 100%의 결론을 보장하지 않는다.

귀납은 구체적인 개별 사례에서 일반적인 법칙 또는 규칙을 찾아낸다.

귀납 논증은 전제가 결론을 개연적으로 보장한다. 귀납은 관찰된 범위 안에서는 참이지만 관찰되지 않은 영역까지 확장하면 결론을 보장할 수 없다.

귀납을 개발 관점에서 보면<br>
API의 호출이 여러번 성공했기 때문에 이 API는 안정적이다라고 할 수 있지만 그 다음에 터질 수 있다.
그렇기 때문에 우리는 로그, 통계, 테스트를 반복한다. 


## 정리
전제가 결론을 

필연적으로 뒷받침한다면 ***연역 논증*** 이고

개연적으로 뒷받침한다면 ***귀납 논증*** 이다. 귀납 논증은 반례가 뒤따를 수 있다.

논증을 단순화 하면 전제와 결론이 서로 뒤바뀐 모습이다.
```
[연역]
전제 - 모든 사람은 죽는다.
결론 - 소크라테스는 죽는다.

[귀납] 
전제 - 소크라테스는 죽는다.
결론 - 모든 사람은 죽는다.
```
중요한 점은 전제와 결론의 포함관계이다.


연역 논증의 경우 결론은 전제에 포함되는 명제이며 <br>
귀납 논증의 경우 결론은 전제의 범위를 넘어서는 명제이다.

따라서 연역 논증의 경우 전제가 참이라면 결론도 참이지만
귀납 논증의 경우 전제가 참이라 해서 결론 또한 참이라는 보장이 없다.


연역 논증으로 인한 결론이 필연적일 수 있는 이유는 결론이 전제에 포함되어 있기 때문이다. 이는 전제를 통해 이미 알고 있는 사실을 반복하는 것에 지나지 않는다.

반대로 귀납 논증은 결론이 전제를 포함하는 구조이므로 결론은 전제의 내용을 벗어난다. 

전제로 인한 결론이 거짓일지도 모르지만 새로운 정보라는 가치를 도출해 낼 수 있다.

---

연역은 이미 알고 있는 원칙을 통해 오류 없는 결론을 도출할 때 유용하며, 프로그래밍의 알고리즘이나 수학적 증명의 기초가 된다.

귀납은 데이터와 경험을 바탕으로 새로운 법칙을 발견할 때 강력한 도구가 되며, 과학적 탐구나 통계적 예측의 핵심이 된다.
